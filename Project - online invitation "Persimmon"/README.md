# pinkvite: бесплатный конструктор приглашений

## Файлы
- index.html — главная
- create.html — конструктор (5 экранов, вступления, вайбы)
- invite.html — страница, которую видит получатель
- style.css, core.js, builder.js — оформление и логика
- server.js — мини-сервер: раздаёт сайт и принимает загрузки музыки/фото
- stickers/ — твои гифки;  music/ — твои треки

## Что вставить (всё в начале core.js)
1. STICKERS — пути к гифкам из папки stickers/
2. HERO_GIF — гифка на главной (можно оставить пустой)
3. MUSIC — готовые треки из папки music/

## Запуск
node server.js   →   http://localhost:3000
Загрузка своих файлов гостем работает только когда сайт запущен через server.js.
Для публикации нужен хостинг с Node.js (Render, Railway, VPS).
На GitHub Pages/Netlify сайт откроется, но кнопки загрузки файлов будут работать только в превью.
