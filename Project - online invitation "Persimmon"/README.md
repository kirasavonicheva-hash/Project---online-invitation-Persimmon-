# pinkvite: бесплатный конструктор приглашений

## Файлы
- index.html — главная
- create.html — конструктор (5 экранов, вступления, вайбы)
- invite.html — страница, которую видит получатель
- style.css, core.js, builder.js — оформление и логика
- server.js — мини-сервер: раздаёт сайт и принимает загрузки музыки/фото
- stickers/ — твои гифки;  music/ — твои треки
